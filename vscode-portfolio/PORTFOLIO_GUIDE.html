🟢 핵심 원칙
React에서 UI는 "데이터의 결과물"입니다.
DOM을 직접 건드리지 않고, 데이터(state)를 바꾸면 화면이 자동으로 업데이트됩니다.

2. React 핵심 개념

2-1. useState — 컴포넌트의 기억

컴포넌트가 기억해야 할 값을 저장합니다. 값이 바뀌면 컴포넌트가 자동으로 다시 그려집니다.

// 기본 형태
const [값, 값바꾸는함수] = useState(초기값)

// 이 포트폴리오에서 사용되는 예
const [theme, setTheme]           = useState('dark')
const [activeSection, setActiveSection] = useState('explorer')
const [sidebarOpen, setSidebarOpen]   = useState(false)

// 값 바꾸기
setTheme('light')       // → 화면 자동 업데이트
setSidebarOpen(true)  // → 사이드바 열림
⚠️ jQuery와 차이점
jQuery: $('.sidebar').show() → DOM 직접 조작
React: setSidebarOpen(true) → 데이터 변경 → React가 DOM 업데이트

2-2. props — 부모에서 자식으로 데이터 전달

// App.jsx (부모) → ActivityBar.jsx (자식)으로 전달
<ActivityBar
  active={activeSection}       // 현재 섹션 이름 전달
  onSelect={handleSectionSelect} // 함수 전달 (자식이 호출)
/>

// ActivityBar.jsx (자식)에서 받기
export default function ActivityBar({ active, onSelect }) {
  // active: 'explorer' | 'skills' | 'projects' | 'contact'
  // onSelect: 아이콘 클릭 시 호출할 함수
  return (
    <button onClick={() => onSelect('skills')}>Skills</button>
  )
}

2-3. useCallback — 함수 캐싱으로 성능 최적화

// useCallback 없으면: App이 리렌더될 때마다 함수가 새로 생성됨
// useCallback 있으면: 의존성 배열이 바뀔 때만 함수 재생성

const handleFileClick = useCallback(
  (file) => {
    openTab(file)
    navigate(file.route)
  },
  [openTab, navigate] // 이 둘이 바뀔 때만 함수 재생성
)
🟢 언제 써야 하나?
자식 컴포넌트에 함수를 props로 전달할 때 씁니다. 없어도 동작하지만, 있으면 불필요한 리렌더링을 방지합니다.

2-4. 커스텀 훅 (useTabs) — 로직 분리

훅(Hook)은 use로 시작하는 함수입니다. 상태 관련 로직을 컴포넌트 밖으로 뽑아내서 재사용할 수 있게 합니다.

// src/hooks/useTabs.js
export function useTabs(initialTabs = []) {
  const [tabs, setTabs]           = useState(initialTabs)
  const [activeTab, setActiveTab] = useState(initialTabs[0]?.id || null)
  //                                              ↑ 옵셔널 체이닝: undefined 방지

  const openTab = useCallback((tab) => {
    setTabs((prev) => {
      if (prev.find((t) => t.id === tab.id)) return prev // 이미 열려있으면 무시
      return [...prev, tab]  // 기존 배열 복사 + 새 탭 추가
    })
    setActiveTab(tab.id)
  }, [])

  return { tabs, activeTab, openTab, closeTab, activateTab }
}

// App.jsx에서 사용
const { tabs, activeTab, openTab, closeTab, activateTab } = useTabs([defaultTab])

2-5. lazy / Suspense — 필요할 때만 로드

// ❌ 일반 import: 앱 시작 시 모든 페이지 코드를 한꺼번에 다운로드
import About from './pages/About'

// ✅ lazy import: About 탭을 클릭할 때만 코드 다운로드

// Suspense: 로딩 중일 때 fallback 표시
<Suspense fallback={<div>로딩 중...</div>}>
  <About />
</Suspense>

4. Vue 3 핵심 개념

4-1. ref / reactive — Vue의 상태 관리

React

const [count, setCount]
  = useState(0)

// 읽기
count

// 쓰기
setCount(1)

Vue 3

const count = ref(0)

// 읽기 (script 안)
count.value

// 쓰기
count.value = 1
// template 안에선 .value 생략
// reactive: 객체 전체를 반응형으로 (form 같은 경우에 유용)
const form = reactive({ name: '', email: '', message: '' })

// .value 없이 바로 접근 가능
form.name = '김석현'

4-2. template 문법

<template>
  <!-- 데이터 출력: {{ }} -->
  <p>{{ profile.name }}</p>

  <!-- 속성 바인딩: : (v-bind 축약) -->
  <div :style="{ width: skill.level + '%' }"></div>
  <a :href="`mailto:${profile.email}`"></a>

  <!-- 이벤트: @ (v-on 축약) -->
  <form @submit.prevent="handleSubmit"></form>
  <!-- .prevent = event.preventDefault() 자동 호출 -->

  <!-- 양방향 바인딩: v-model -->
  <input v-model="form.name" />
  <!-- 입력하면 form.name 자동 업데이트 -->

  <!-- 조건: v-if / v-else -->
  <span v-if="!submitted">send()</span>
  <span v-else>✓ 전송 완료</span>

  <!-- 반복: v-for -->
  <li v-for="skill in group.items" :key="skill.name">
    {{ skill.name }}
  </li>
</template>

4-3. onMounted — 컴포넌트가 화면에 붙은 직후 실행

React

useEffect(() => {
  // DOM 조작 또는 초기화
}, []) // 빈 배열 = 최초 1회만

Vue 3

onMounted(() => {
  // DOM 조작 또는 초기화

    skillGroups.forEach((g) =>

5. React + Vue 통합 방식

이 포트폴리오의 가장 특이한 점입니다. React 컴포넌트 안에 Vue 앱을 마운트합니다.

// src/components/pages/Skills.jsx
import { useEffect, useRef } from 'react'
import { createApp } from 'vue'
import SkillsChart from '../../vue-components/SkillsChart.vue'

export default function Skills() {
  const mountRef = useRef(null)  // DOM 요소 참조
  const appRef   = useRef(null)  // Vue 앱 인스턴스 저장

  useEffect(() => {
    // 마운트: mountRef.current (div)에 Vue 앱 올리기
    appRef.current = createApp(SkillsChart)
    appRef.current.mount(mountRef.current)

    // 언마운트: Skills 탭 닫을 때 Vue 앱도 정리
    return () => {
      appRef.current.unmount()
      appRef.current = null
    }
  }, [])

  return <div ref={mountRef} style={{ height: '100%' }} />
  // 이 div를 Vue가 점령함
}
🟢 왜 이렇게 하나?
Vite에 @vitejs/plugin-react와 @vitejs/plugin-vue를 동시에 설치하면
같은 프로젝트에서 .jsx와 .vue 파일을 모두 처리할 수 있습니다.
"포트폴리오에서 두 프레임워크를 모두 다룰 줄 안다"를 직접 보여주는 방식입니다.

10. React vs Vue 핵심 비교표

개념ReactVue 3
단순 상태useState(0)ref(0) → val.value
객체 상태useState({})reactive({})
초기화 (mount)useEffect(fn, [])onMounted(fn)
함수 캐싱useCallback(fn, deps)필요 없음 (자동)
props 받기function Comp({ prop })defineProps(['prop'])
이벤트onClick={fn}@click="fn"
양방향 바인딩value={v} onChange={fn}v-model="v"
조건 렌더{조건 && <El/>}v-if="조건"
리스트 렌더{list.map(el => <El/>)}v-for="el in list"
CSS 스코프CSS Modules (.module.css)<style scoped>
템플릿JSX (JS 안에 HTML)<template> 블록
